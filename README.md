## 📖 Overview

**Apex Reader** is a high-performance PDF processing studio built to replace outdated PDF viewers. It combines advanced PDF manipulation tools—such as document splitting, merging, compression, page organization, digital signing, and OCR—with custom visual aesthetics inspired by iconic anime themes.

Whether studying late at night or managing heavy document workflows, Apex Reader keeps your workspace eye-friendly through its native **Smart Dark Mode**, which intelligently adapts page content while preserving embedded images, diagrams, and figures.

## ✨ Key Features

* **⚡ Core PDF Engine:** High-speed canvas rendering with page zooming, rotation, continuous scrolling, and text search.
* **🌙 Image-Aware Smart Dark Mode:** Darkens document page backgrounds while preventing color inversion or quality loss on embedded graphics and photos.
* **🎨 Custom Aesthetic Themes:** Seamlessly switch UI accents and background styling between themes like *Naruto Kurama*, *Sasuke Chidori*, *Itachi Sharingan*, *Cyberpunk Glass*, and *Emerald Glow*.
* **🧰 Full Processing Suite:**
  * **Export & Flatten PDF:** Save filled forms and annotations permanently into base layers.
  * **Combine & Split:** Merge multiple documents or extract targeted page ranges.
  * **Compress PDF:** Reduce file size while preserving document legibility.
  * **Page Organizer:** Reorder, rotate, or remove individual pages.
  * **Scan & OCR Engine:** Extract selectable text layers using built-in OCR.
  * **Digital E-Sign & Watermarking:** Draw legal e-signatures or overlay custom watermark stamps.
* **🚀 Hardware Acceleration:** Powered by GPU acceleration for smooth navigation through multi-page documents.
