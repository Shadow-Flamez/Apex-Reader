# Apex Reader 🚀

A fast, feature-packed PDF and document reader designed to give traditional PDF viewers a massive upgrade in style and personalization. Powered by dynamic anime visual themes and an eye-friendly Smart Dark Mode, Apex Reader combines high-performance document handling with vibrant, modern aesthetics.

---

## ✨ Features

* **⚡ Acrobat-Level Core Engine:** High-speed PDF rendering, fast page navigation, bookmarking, text search, and document management.
* **🎨 Anime Aesthetic Themes:** Choose from custom color palettes, background accents, and UI styling inspired by popular anime aesthetics.
* **🌙 Smart Dark Mode:** High-contrast, low-fatigue reading mode that intelligently darkens pages without inverting or ruining images and diagrams.
* **🔍 Clean Workspace:** Minimalist interface built to keep your reading immersive and distraction-free.
* **🚀 Lightweight Performance:** Built for speed with minimal memory overhead, ensuring instant file loading.
