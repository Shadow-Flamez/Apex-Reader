## ✨ Features

* **⚡ Core Document Engine:** High-speed PDF rendering, fast page navigation, bookmarking, text search, and document management.
* **🎨 Anime Aesthetic Themes:** Custom color palettes, background accents, and UI styling inspired by popular anime aesthetics.
* **🌙 Smart Dark Mode:** High-contrast, low-fatigue reading mode that intelligently darkens pages without ruining embedded images or diagrams.
* **🧰 Full Processing Suite:** Compress, split, combine, organize pages, OCR, and add digital signatures seamlessly.
* **🚀 Lightweight Performance:** Fast application startup with minimal CPU and memory overhead.
